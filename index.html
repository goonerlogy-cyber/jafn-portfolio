01 — Selected work

01 / SEARCH ENGINE

Sift

Search, explained.

A browser search engine over 10,000 film-style records. Type a query, make a typo, narrow results, and inspect why one result outranks another. After load, queries run locally in a worker.

  • Compressed radix trie — prefix search + bounded typo matching
  • Positional inverted index + bitset facets
  • Six ranking criteria → top-K heap with full tie-break explanation
  • Request/response exposed as JSON in the playground

02 / LANGUAGE + COMPILER

Kiln

Source to WebAssembly.

Compiles a small statically typed language into real WebAssembly binaries in the browser. Every stage is inspectable — tokens, syntax trees, emitted bytes, program output.

  • Pipeline: source → lexer → parser → type checker → binary emitter → WASM → worker runtime
  • Mandelbrot demo writes 65,536 pixels through a canvas host
  • Isolated worker execution with cancellation + 8s deadline
  • No unbounded fallback on the UI thread

03 / INTERACTIVE GRAPHICS

Eddy

Paint the flow.

Interactive fluid playground. Mouse and touch painting, tunable presets, shareable looks. Raw WebGL2 passes turn velocity, pressure, and dye into something you can manipulate directly.

  • Semi-Lagrangian advection, vorticity confinement, pressure solve, gradient subtraction
  • Ping-pong framebuffers, separate sim/dye resolutions
  • Presets, palettes, local PNG capture, settings in URL fragments
  • Optional audio-reactive input with clean mic lifecycle
