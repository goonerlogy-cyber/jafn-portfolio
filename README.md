Soft, playful developer portfolio focused on search engines, compilers, and interactive graphics.

Inspired by the Catto aesthetic, built for [goonerlogy-cyber](https://github.com/goonerlogy-cyber).

- **Kiln** — Small language → WebAssembly
- **Eddy** — Interactive fluid graphics
- **q** — AI/ML paper reproductions
- **area** — Geometry calculator
